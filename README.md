# New Tools for the Bifrost Suite

Project Sonar: Uptime Monitor & Status Page (Simple)
Description: A reliable service that monitors your websites and APIs 24/7. It sends instant alerts via email or Slack if a service goes down and can power a public-facing status page to keep users informed.

Project Nexus: Webhook Inspector & Request Bin (bit-Hard)
Description: An essential debugging tool that provides a unique URL to capture and inspect incoming webhook requests from services like Stripe or GitHub. It offers a clean UI to view headers, payloads, and other request data in real-time.

Project Chronos: Serverless Cron Job Runner (Simple)
Description: A simple, powerful scheduler that allows developers to trigger HTTP requests at specific intervals or on a cron schedule. Perfect for automating recurring tasks like data cleanup or generating nightly reports without managing a server.

Project Relay: Real-time WebSockets for Serverless (bit-Hard)
Description: A managed "WebSockets-as-a-Service" platform designed for serverless frameworks like Next.js on Vercel. It handles persistent WebSocket connections, allowing developers to easily add real-time features to their serverless applications via a simple REST API.
